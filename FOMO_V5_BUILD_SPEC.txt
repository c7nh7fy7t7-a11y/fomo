# FOMO V5 — Social Core + Map Pinning + Feed + Profiles + Full Visual Redesign

Start from the latest STABLE working version of FOMO.

This is not a prototype redesign.

The goal of V5 is to make FOMO feel like a legitimate consumer social app that university students would actually want installed on their phones.

The biggest priorities are:

1. Add precise interactive location pinning for events.
2. Build a fully functional social Feed.
3. Add likes/reactions/comments/tagging/views.
4. Build clean modern user profiles.
5. Preserve and improve 1-to-1 messaging.
6. Completely redesign the app visually.
7. Use the ATTACHED BLACK-AND-WHITE LOWERCASE "fomo" image as the official branding direction.
8. Make dark mode the permanent/default interface.
9. Preserve all current Supabase/event/friend/privacy functionality.
10. Prepare the app for multi-user testing and eventually TestFlight.

Do NOT sacrifice backend reliability for visual polish.

==================================================

==================================================
