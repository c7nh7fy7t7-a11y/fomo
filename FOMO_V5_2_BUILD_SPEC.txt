# FOMO V5.2 — VISUAL POLISH, MEDIA, NAVIGATION & CREATE EXPERIENCE

START FROM THE CURRENT WORKING FOMO V5.1 BUILD.

V5.1 has now been tested successfully across multiple phones using Expo Tunnel.

Confirmed working:

- authentication
- signup/login
- events
- event creation
- event joining
- request/approval system
- protected exact locations
- map
- Feed
- photo posting
- likes
- double-tap likes
- reactions
- comments
- comment timestamps
- tagging
- profiles
- profile views
- messaging
- realtime
- Supabase persistence
- multi-user usage
- cross-network usage through Expo Tunnel

DO NOT unnecessarily rewrite these systems.

V5.2 is primarily a UX/UI refinement version.

The goal is to take FOMO from:

"functional social app"

to:

"a social app that actually feels polished, colorful, fluid and enjoyable to use."

==================================================
V5.2 MAIN GOALS
==================================================

1. Make Discover / Feed navigation larger and more prominent.
2. Allow horizontal swiping between Discover and Feed.
3. Completely improve photo/media sizing.
4. Remove the forced square-photo appearance.
5. Add proper video posting.
6. Redesign the Create button experience.
7. Fix clipping at the bottom of the Map screen.
8. Add tasteful color throughout FOMO.
9. Replace the overly-black background with richer charcoal tones.
10. Add significantly more visual polish and personality.
11. Preserve all currently working functionality.

This should feel like an evolution of FOMO rather than another complete redesign.

==================================================
1. REDESIGN DISCOVER / FEED CONTROL
==================================================

The current:

Discover     Feed

control at the top of Home is too small and understated.

Make these two sections a strong visual anchor.

Center the control horizontally.

Make the labels noticeably larger.

Example:

              Discover       Feed
              ━━━━━━━━

or another clean social-app style.

Requirements:

- centered
- approximately equal width
- larger font
- easy to tap
- clearly visible
- selected page obvious
- clean animated selected indicator

Do NOT make them giant rectangular buttons.

They should still feel elegant.

Use typography and a sliding indicator rather than two bulky cards.

==================================================
SWIPE BETWEEN DISCOVER AND FEED
==================================================

Users should be able to change pages in TWO ways:

1. Tap Discover / Feed
2. Swipe horizontally

Example:

Discover

→ swipe left →

Feed

Feed

→ swipe right →

Discover

The animation should follow the user's finger naturally.

The top selection indicator should move/change at the same time.

Use a proper horizontal pager / gesture system.

Do NOT fake this with a gesture that fires only after the swipe finishes.

It should feel native.

IMPORTANT:

Horizontal page swiping must not interfere with normal vertical scrolling inside the Feed or Discover screen.

Vertical movement should continue to scroll normally.

A horizontal gesture should require enough horizontal intent that normal scrolling does not accidentally switch pages.

==================================================
2. COMPLETELY IMPROVE MEDIA SIZING
==================================================

Current Feed photos look too square.

REMOVE the forced square image design.

Photos should respect their original proportions much more naturally.

The Feed should intelligently support:

PORTRAIT

LANDSCAPE

NEAR-SQUARE

WIDE

TALL

images.

Do NOT place every image inside the same square container.

==================================================
DYNAMIC IMAGE ASPECT RATIOS
==================================================

Use the real source media dimensions.

Example:

Portrait photo:

┌────────────────────────┐
│                        │
│                        │
│         PHOTO          │
│                        │
│                        │
│                        │
└────────────────────────┘

Landscape:

┌────────────────────────┐
│         PHOTO          │
│                        │
└────────────────────────┘

Near-square:

Use a naturally appropriate ratio.

The Feed should feel more photographic.

==================================================
NO BLACK LETTERBOX BORDERS
==================================================

Do NOT show ugly black strips beside or above photos.

Because the rest of the application is already dark, letterboxing makes the interface look unfinished.

Instead:

Use the media's actual aspect ratio where practical.

Set:

width = available Feed width

and derive height from the image's natural aspect ratio.

Use sensible minimum and maximum heights.

For extremely tall/wide images:

allow a small intelligent crop using cover-style behavior rather than huge empty borders.

Never stretch or distort an image.

==================================================
MEDIA CONTAINER
==================================================

Feed photography should feel immersive.

Use:

- near edge-to-edge media
- subtle rounded corners
- approximately 18–22px corner radius
- media that visually dominates the post
- minimal unnecessary padding around the image

Do NOT wrap the photograph inside three layers of cards.

==================================================
3. ADD VIDEO POSTS
==================================================

The Create experience should now support:

PHOTO

VIDEO

PARTY / EVENT

Video does NOT mean creating a TikTok-style video feed.

It simply means Feed posts can contain a video instead of a photo.

==================================================
VIDEO POSTING
==================================================

Allow users to:

Choose video

Preview video

Add caption

Link event

Tag friends

Post

Videos should upload through Supabase Storage.

Extend the existing Feed media architecture cleanly rather than creating an entirely unrelated post system.

Media should have a type such as:

image
video

==================================================
VIDEO FEED UI
==================================================

Videos should appear naturally within the normal Feed.

Use the original video aspect ratio where possible.

Display:

video thumbnail / first frame

play button

duration where available

Tap:

play video

Do NOT autoplay every video simultaneously.

Do NOT create a full-screen endless video feed.

For V5.2, normal inline playback is enough.

Only actively playing videos should consume significant resources.

==================================================
VIDEO STORAGE
==================================================

Update backend/storage policies safely.

Maintain RLS.

Users may only create media associated with posts they own.

Never expose service-role credentials.

Use reasonable limits for:

- file size
- supported formats
- upload errors

If upload fails:

do not create a permanently broken post.
